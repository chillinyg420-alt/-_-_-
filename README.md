# 재고이동 레이더 (Inventory Movement Radar)

매장/창고별 엑셀 파일(가격표, 점별판매현황, 점별재고, 창고재고, 매출분석표)을 브라우저에서 업로드하면
**재고이동이 필요한 특이 SKU**를 자동으로 찾아주는 정적 웹 도구입니다.
별도 서버나 백엔드 없이 `index.html` 파일 하나로 동작하며, 업로드한 데이터는 외부로 전송되지
않고 브라우저 안에서만 처리됩니다.

## 사용 방법

### 1) 로컬에서 바로 열기
`index.html` 파일을 더블클릭하거나 브라우저로 열면 바로 실행됩니다. 별도 설치가 필요 없습니다.

### 2) GitHub Pages로 배포해서 팀과 공유하기
1. 이 저장소를 GitHub에 올립니다 (저장소 이름 예: `inventory-radar`).
2. GitHub 저장소 페이지에서 **Settings → Pages**로 이동합니다.
3. **Source**를 `Deploy from a branch`로 선택하고, 브랜치는 `main`, 폴더는 `/root`(또는 `/`)로 지정한 뒤 저장합니다.
4. 몇 분 후 `https://<github-아이디>.github.io/<저장소이름>/` 주소로 접속하면 누구나 브라우저만으로 이 도구를 사용할 수 있습니다.
   (사내 인트라넷이 아니라 인터넷에 공개되는 주소이니, 민감한 데이터가 포함된 파일을 실제로 업로드해 캡처/스크린샷을 공유하지 않도록 주의하세요.)

## 업로드해야 하는 파일

좌측 사이드바에서 아래 5종류의 엑셀 파일을 업로드합니다. (창고재고, 매출분석표는 선택 항목)

| 항목 | 필수 컬럼 | 필수 여부 |
|---|---|---|
| 가격표 | 스타일, 컬러, 감가율, 판매가, 브랜드, 상품 | 필수 |
| 점별판매현황 | 점, 스타일, 컬러, 수량(합계) | 필수 |
| 점별재고 | 점, 스타일, 컬러, 현재재고 | 필수 |
| 창고재고 | 창고, 스타일, 컬러, 현재재고 | 선택 |
| 매출분석표(입고년월) | 년도, 월, 스타일, 컬러 (시트명: 신발) | 선택 |

## 참고

- 이 저장소의 `index.html`은 이전에 업로드했던 단가표(약 5만 SKU) 데이터를 제거한 **빈 템플릿** 버전입니다.
  파일을 열면 데이터 없이 시작하며, 사용할 때마다 위 엑셀 파일들을 다시 업로드하면 됩니다.
- 클라이언트 사이드(브라우저)에서만 동작하는 정적 페이지이므로, 이 저장소는 GitHub Pages, Netlify, 사내 정적
  파일 서버 등 어디에도 그대로 올려서 쓸 수 있습니다.

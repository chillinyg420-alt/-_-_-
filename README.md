# 재고이동 레이더 (Inventory Movement Radar)

매장 간 재고이동이 필요한 SKU를 찾아주는 도구입니다. 두 방향을 모두 지원합니다.

- **받을 재고** — 우리 매장은 잘 나가는데, 다른 매장엔 잠자고 있는 재고 찾기
- **보낼 재고** — 우리 매장엔 잠자고 있는데, 다른 매장에서 잘 나가는 재고 찾기

`index.html` 파일 하나로 동작하는 정적 페이지이며, 데이터는 이미 파일 안에 담겨 있어
여는 즉시 바로 쓸 수 있습니다.

## 사용 방법

1. 아래 GitHub Pages 주소(또는 `index.html`을 직접 열어서) 접속
2. 사이드바 상단에서 **받을 재고 / 보낼 재고** 중 방향을 선택
3. 왼쪽 사이드바에서 **내 매장**을 선택
4. 표에 뜨는 특이 SKU 확인
   - 받을 재고 모드: "판매없음"은 즉시 이관 후보, "판매부족"은 검토 대상
   - 보낼 재고 모드: "체화재고"는 즉시 이관 후보, "판매열세"는 검토 대상
5. 필요하면 브랜드·카테고리·판매(재고) 상위 개수 등 조건을 조정

별도 설치나 로그인이 필요 없고, 파일을 새로 올릴 필요도 없습니다.

## GitHub Pages 주소 확인/설정

저장소 **Settings → Pages**에서 Source를 `Deploy from a branch` → 브랜치 `main` / `/ (root)`로
설정하면 몇 분 뒤 `https://<깃허브아이디>.github.io/<저장소이름>/` 주소가 활성화됩니다. 그 화면
위쪽에 뜨는 "Your site is live at ..." 링크가 실제 접속 주소예요. 이 링크는 인터넷에 공개되는
주소이니, 링크 공유 범위에 유의해주세요.

## 데이터 최신화 (관리자용)

이 페이지에 들어있는 데이터는 특정 시점의 스냅샷입니다. 최신 데이터로 갱신하려면:

1. 최신 엑셀 5종(가격표, 점별판매현황, 점별재고, 창고재고, 매출분석표)을 준비
2. 그 파일들을 Claude에게 전달해 새 `index.html`을 요청
3. 받은 파일로 이 저장소의 `index.html`을 덮어쓰기(같은 파일명으로 재업로드)

일반 사용자는 이 과정을 몰라도 되고, 페이지에는 업로드 화면이 따로 없습니다 — 관리자가 위 과정을
거쳐 갱신한 스냅샷을 그대로 보게 됩니다.
